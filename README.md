# Portfolio

My personal portfolio site — live at **[liams.dev](https://liams.dev)**.

A single-page site I designed in Figma and built from scratch with vanilla HTML, CSS and JavaScript. It introduces who I am, the work I do as a designer & developer, and how to get in touch.

🔗 **Live:** https://liams.dev
🎨 **Design:** [figma.com/@LiamMagnier](https://figma.com/@LiamMagnier)

## Features

- Responsive single-page layout (Home · About · Projects · Contact)
- Bilingual content with a FR / EN language toggle
- Clean, minimal design built from a custom Figma mockup
- Lightweight — no framework, just HTML, CSS and JavaScript

## Tech stack

- **HTML5** & **CSS3**
- **JavaScript** (vanilla)
- **Figma** for design

## Project structure

```
Portfolio/
├── assets/      # images and media
├── css/         # styles
├── js/         # scripts (interactions, language toggle)
└── index.html   # entry point
```

## Run locally

It's a static site — no build step required.

```bash
git clone https://github.com/LiamMagnier/Portfolio.git
cd Portfolio
# then just open index.html in your browser
```

> Tip: for live-reload while editing, use the VS Code "Live Server" extension.
